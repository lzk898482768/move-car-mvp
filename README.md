# 扫码挪车 - 免费静态版

这是一个完全免费、纯静态的扫码挪车项目。

它的目标很直接：

- 车主在浏览器里本地生成挪车二维码
- 访客扫码后直接联系车主
- 不依赖后端、数据库、云函数或短信服务
- 可以直接部署到 GitHub Pages、腾讯云 COS、Netlify、Vercel 等静态站点

## 当前版本特点

- 本地填写车牌和联系方式
- 自动生成访客链接和二维码
- 访客页支持：
  - 拨打电话
  - 发送短信
  - 复制提醒文案
  - 复制微信号
  - 打开自定义联系页
- 支持打印挪车卡片

## 适用场景

适合：

- 想完全免费使用
- 只需要小范围试用
- 不想维护后端服务
- 希望国内访问更简单

不适合：

- 需要真正匿名的服务端通知中转
- 需要通知日志、限流和后台管理
- 需要远程撤销或更新已经打印的二维码

## 页面说明

- `public/index.html`：车主生成二维码
- `public/move.html`：访客扫码联系车主
- `public/demo.html`：流程演示
- `public/setup.html`：使用说明
- `public/privacy.html`：隐私说明

## 本地预览

如果你本机有 Node.js，可以运行：

```bash
npm run serve:public
```

然后打开：

```text
http://localhost:4173
```

如果你没有 Node.js，也可以把 `public/` 目录部署到任意静态托管平台后直接使用。

## 隐私说明

这个免费静态版不会把联系信息上传到服务器，但二维码本身包含联系配置，因此不适合放入高度敏感信息。
